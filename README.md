⬛ WeatherMap Project

⬛ Project Overview 
An advanced asynchronous Single Page Application designed to provide real-time weather data, interactive mapping, and an AI-powered chatbot assistant for a seamless and modern user experience.

⬛ Tech Stack 
▪️ HTML5 (Semantic Structure)
▪️ CSS3 (Glassmorphism Design & Responsive Layout)
▪️ Vanilla JavaScript (ES6+ Modules)
▪️ Leaflet.js (Interactive Maps)
▪️ OpenWeatherMap API & Nominatim API

⬛ How to Run 
▪️ Clone the repository to your local machine.
▪️ Open the project folder in Visual Studio Code.
▪️ Install the "Live Server" extension and click "Open with Live Server".
▪️ Open your browser and navigate to the localhost link (e.g., http://127.0.0.1:5500/index.html) or the live GitHub Pages deployment link.
